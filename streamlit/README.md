# 🚗 Smart Parking System

An IoT and AI-based smart parking availability and reservation system.

## Problem

Drivers waste time and fuel searching for parking spaces,
especially in high-congestion areas.

Parking owners also have difficulty providing information about
their available parking spaces.

## Solution

The Smart Parking System connects drivers and parking owners.

### Driver Features

- Register/Login
- Find parking
- View available slots
- View parking price
- Reserve parking
- Navigate to parking
- View booking status

### Parking Owner Features

- Register/Login
- Add parking location
- Set parking price
- Set number of slots
- View booking requests
- Accept/Reject bookings
- Update parking availability

### AI Features

- Vehicle detection
- Parking slot detection
- Occupancy detection
- Parking availability prediction
